# eventsurvey 0.1.0

* Added strict validation that both core estimators use an untransformed
  `outcome ~ time` formula, preventing unsupported transformations or
  multi-variable specifications from being interpreted as the documented
  time-only model.
* Added `coef()` and `confint()` methods for fitted `eventsurvey` objects.
  The confidence-interval extractor returns the honest interval by default and
  provides deliberate access to the conventional interval.
* Reports now state the units and interpretation limits, record input, used,
  and omitted rows plus total represented responses, and explain that
  multi-analysis reports neither pool estimates nor adjust for multiple
  comparisons.
* Prepared version 0.1.0 with a package citation, a live R-CMD-check badge,
  stricter continuous-integration failure on warnings, and structural tests
  for report safeguards.

* Added the documented, lazily loaded `sample_data` respondent-level dataset,
  generated by `simulate_eventsurvey(seed = 10)`, so a first analysis requires
  only loading the package and calling `eventsurvey()`.
* Renamed `pre_periods` to `schedule` and added automatic diagnostics for
  calendar coverage, period sample sizes, variance information, reference
  windows, and elapsed fitting/forecasting spans.
  A dedicated article explains each check with complete, sparse, low-count,
  pooled-variance, and limited-history examples.
* Added `eventsurvey_report()` for generating a self-contained HTML report
  with estimates, settings, coverage diagnostics, and standard figures from
  either core estimator in one pipeline. Reports now accept a custom title and
  a named list of fitted objects for separately presented multiple outcomes.
  Survey coverage now uses one combined plot with observed means and a compact
  response-count distribution along the x-axis. Counterfactual plots label
  every fitted and forecast period explicitly rather than using automatic
  fractional axis breaks. All time-axis plots now use the same blue dashed
  event marker, and forecast-diagnostic plots include an explicit `0` tick.
* Consolidated the two published-application articles into one overview and
  added separate self-contained HTML reports for Bateson--Weintraub (2022) and
  Epifanio--Giani--Ivandic (2023).
* The core estimators now use conventional defaults wherever they can be
  inferred safely: `event_time = 0` in both interfaces and columns named `n`
  and `variance` in `eventsurvey_summary()`.
* Sparse survey schedules are now supported by default with
  `schedule = "observed"`. Fitted objects report missing pre-event and
  forecast periods and elapsed rolling-window spans; strict consecutive-period
  validation remains available with `schedule = "consecutive"`.
* Observed-period reference windows now mirror an excluded event period by
  skipping one observed period between fitting and forecasting windows.
* Added a simulation article comparing complete daily fieldwork with a sparse
  schedule, including coverage, counterfactual, gap, and estimand diagnostics.
* Initialized the R package, testing, continuous-integration, and pkgdown
  website environment.
* Added the formula-based `eventsurvey()` estimator with analytic
  bounded-misspecification-error inference, period-specific estimates,
  rolling forecast diagnostics, Date support, and explicit event-day rules.
* Added `simulate_eventsurvey()` and four `ggplot2` visualizations.
* Added complete getting-started, data-preparation, example, methodology,
  sensitivity, and FAQ articles.
