# AI Collaboration and Project History

This repository follows the Guide to Recording AI Use. Treat this directory as
the `eventsurvey` R-package project root and keep one authoritative, private
history in `project_history/YYYY-MM-DD by Agent.md`. Append substantive work;
never overwrite earlier entries.

Keep `project_history/`, `_source/`, and local research inputs out of package
builds and public releases. The `_source/` directory contains private source
materials from the associated research repository and must remain Git-ignored.

For substantive R analysis, tables, or figures, follow Yusaku Horiuchi's global
R and figure style instructions. Record exact commands, verification results,
files affected, package/runtime versions, and exposed model/runtime metadata.
